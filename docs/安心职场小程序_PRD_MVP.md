# 安心职场小程序 PRD（MVP版）

## 1. 产品概述

- **产品名称（暂定）**：安心职场
- **目标用户**：职场困顿人群（按阶段）
  - 初入职场（0-2年）
  - 职场成长期（2-5年）
  - 职场成熟期（5-15年）
  - 职场末期（15年以上）
- **核心目标**：
  - 帮助用户建立个人评价体系
  - 缓解焦虑并规划职业路径
  - 通过游戏化反馈提升安全感与成就感

---

## 2. 核心功能模块

### 2.1 用户旅程

1. **探索问题（5问诊断）**
   - 覆盖维度：心理情绪、职场困境、生活状态、能力资源、价值观/动机
   - 输出：问题画像卡
   - 游戏化：进度条、动态提示

2. **定义未来目标**
   - 用户选择未来理想状态（工作/生活成就）
   - 支持拆解为短期/长期目标
   - 游戏化：目标图标、任务等级

3. **规划路径**
   - 规则引擎生成个性化行动路径（知识库 + 问题类型 + 职场阶段）
   - 拆解为每日/每周任务
   - 游戏化：成长地图、成就徽章

4. **行动成长**
   - 用户完成任务后实时反馈进度
   - 游戏化：经验值、徽章、等级、排行榜（可选）

5. **复盘与进化**
   - 周期性反馈：情绪、任务完成率、能力提升
   - 系统动态调整行动路径与任务
   - 游戏化：成长雷达图、积分奖励

### 2.2 知识与路径库

- 问题分类库：心理、职场、生活
- 职场阶段模型：初入职场、成长期、成熟期、末期
- 行动方案库：学习任务、实践任务、思考任务、社交任务
- 案例与方法库：真实职场案例、方法工具
- 动态微调机制：基于完成情况自动调整任务路径

---

## 3. 前端设计与交互

### 3.1 页面结构

- **首页**：欢迎页 + 快速进入探索问题
- **问题诊断页**：5个问题（单选/多选/滑动条）+ 进度提示
- **未来目标页**：列表/图标化选择目标
- **路径规划页**：可执行任务列表 + 开始任务入口
- **行动执行页**：任务打卡、完成反馈、经验值/徽章
- **复盘页**：雷达图展示情绪/能力/任务完成率 + 调整下一周期
- **底部导航 Tab**：探索 / 规划 / 行动 / 复盘 / 我的

### 3.2 交互原则

- 简洁直观，突出进度与成就感
- 最少点击：每步仅保留一个核心操作按钮

---

## 4. 后端逻辑

### 4.1 用户管理

- 用户基础信息
- 职场阶段标签
- 历史任务与成长数据

### 4.2 问题诊断引擎

- 5问得分与标签映射
- 输出问题类型权重
- 基于权重匹配路径库

### 4.3 目标与路径生成

- 根据目标 + 问题画像 + 职场阶段生成路径
- 拆解短期/长期任务

### 4.4 任务管理

- 任务状态：待完成 / 已完成
- 任务类型：周期任务 / 一次性任务

### 4.5 成长反馈系统

- 经验值计算
- 等级成长
- 徽章解锁
- 周期复盘数据生成

### 4.6 动态微调机制

- 根据完成率与复盘反馈调整后续任务

### 4.7 知识库系统

- 问题分类库
- 职场阶段模型
- 行动方案库
- 案例与方法库

## 5. 埋点设计（MVP）

| 事件 | 触发条件 | 采集内容 | 用途 |
|---|---|---|---|
| `app_open` | 小程序启动 | 时间、用户ID | 统计活跃 |
| `start_diagnosis` | 开始问题诊断 | 用户阶段 | 行为分析 |
| `finish_question` | 完成单题 | 题目答案、耗时 | 个性化推荐与问题来源分析 |
| `set_goal` | 设置目标 | 目标类型、职场阶段 | 目标偏好分析 |
| `task_complete` | 完成任务 | 任务ID、用时、阶段 | XP计算、路径微调 |
| `feedback_submit` | 提交复盘 | 情绪评分、满意度 | 优化路径与规则迭代 |
| `badge_earned` | 获得徽章 | 徽章类型、时间 | 激励机制分析 |
| `path_adjusted` | 路径微调 | 原任务、调整后任务 | A/B路径效果验证 |

## 6. 最短实现路径（MVP）

### 6.1 MVP目标

最短时间落地核心价值：**建立安全感 + 形成成就反馈闭环**。

### 6.2 前端范围

- 首页 + 5问诊断页
- 目标设定页
- 任务列表页 + 打卡完成
- 简单复盘页（雷达图仅展示任务完成率）

### 6.3 后端范围

- 用户信息管理 + 职场阶段存储
- 问题诊断逻辑（规则匹配输出问题类型）
- 目标拆解与简单任务匹配
- 任务完成记录
- 经验值计算 + 简单等级系统

### 6.4 知识库范围

- 核心问题分类
- 核心任务库（按职场阶段）

### 6.5 游戏化范围

- 完成任务后发放经验值
- 升级与基础徽章

### 6.6 埋点最小集

- `app_open`
- `start_diagnosis`
- `finish_question`
- `task_complete`
- `set_goal`
- `feedback_submit`

### 6.7 实现原则

- 初期不做复杂算法，先用规则匹配生成路径
- 优先做完“诊断 → 任务 → 打卡 → 反馈”基础闭环
- 后续迭代再扩展动态微调、社交、排行榜、AI推荐

---

## 7. 建议数据模型（核心表）

- `users`：基础信息、职场阶段、注册信息
- `diagnosis_records`：5问答案、问题标签、权重结果
- `goals`：用户目标、短期/长期拆解、状态
- `paths`：路径版本、任务集合、生成规则来源
- `tasks`：任务类型、难度、状态、奖励
- `task_logs`：打卡记录、耗时、完成质量
- `growth_stats`：等级、经验值、徽章、周期统计
- `event_logs`：埋点事件与属性
