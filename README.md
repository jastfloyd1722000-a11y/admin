# 安心职场 · 微信小程序 MVP Demo

这是可直接在**微信开发者工具**运行的 Demo，已拆分为页面结构：

- `pages/explore`：5问诊断（探索）
- `pages/plan`：目标设定 + 路径规划
- `pages/action`：任务执行 + XP/等级/徽章
- `pages/review`：复盘与下周期建议

## 本地运行

1. 打开微信开发者工具
2. 选择“导入项目”，目录指向本仓库根目录
3. AppID 可使用测试号（已配置 `touristappid`）
4. 编译后即可通过底部 Tab 体验完整流程

## 项目结构

- `app.json`：页面路由与 tabBar
- `app.js`：全局状态（诊断、目标、任务、成长指标）
- `app.wxss`：全局样式
- `pages/*`：按流程拆分页面

> 说明：当前为 MVP 演示版，使用前端内存状态，未接入后端接口。
